# QuestStory (퀘스트 세 줄 이야기)

한국어 클라이언트용. 퀘스트를 **받을 때**와 **완료할 때**, 그 퀘스트가 어떤 이야기인지 세 줄로 알려 주는 작은 창이 뜬다.
목표(무엇을 몇 개)는 게임이 보여 주는 그대로 따로 나온다.

## 설치 · 업데이트
- WowUp → **Install from URL** → `https://github.com/Jinhyuk772/QuestStory` (이후 업데이트는 WowUp 버튼 하나)
- 직접 설치: [Releases](https://github.com/Jinhyuk772/QuestStory/releases) 의 zip 을 `Interface\AddOns\` 에 풀기

## 쓰기
- 아무것도 안 해도 된다. NPC 가 퀘스트 내용을 보여 줄 때(수락 전)와 보상 창이 열릴 때(완료 전) 창이 알아서 뜬다.
- 창은 저절로 사라지지 않는다. 오른쪽 위 **줄이기** 단추로 작은 막대로 줄이고, 막대(또는 **펼치기**)를 누르면 다시 펼쳐진다. **닫기** 단추는 창을 닫는다. 줄여 놔도 새 퀘스트를 감지하면 알아서 펼쳐진다.
- 여러 개를 연달아 받으면 **이전 · 다음** 단추로 넘겨 본다. 창은 언제든 드래그로 옮긴다.
- `/qs 최소화` · `/qs 열기` · `/qs 자동 30` (30초 뒤 스스로 줄어듦, 0 = 끔)
- `/qs 상태` — 안 뜰 때 확인용(버전 · 받은 신호 · 창 상태)
- `/qs 테스트` — 창이 잘 뜨는지 보기
- `/qs 이동` — 창 옮기기 · `/qs 크기` — 창 크기
- `/qs 마지막` — 방금 본 이야기 다시 보기
- `/qs 끄기` · `/qs 켜기` · `/qs 초기화`

## 들어 있는 것
- 호드 퀘스트 2,843개(레벨 1–60, 직업 전용 포함). 이야기가 없는 퀘스트는 창이 뜨지 않는다.
